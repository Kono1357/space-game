# 观景台（示例 mod）

这个文件夹是一个完整的 mod。**没有一行代码**，全是 JSON。

## 装法

放进 `mods/` 目录，然后重新构建：

```
python build_space.py
```

或者不重新构建：打开游戏，按 **F2** 打开装 mod 的面板，把 `mod.json` 里的 JSON 整份（或只粘 `data` 里的内容块）贴进去，点「应用并重载」，**立刻生效**。
粘过的 mod 会存在浏览器里，下次打开还在。点「清空已装的 mod」可以撤掉。
内容有问题按 **F3** 看校验报告（错误、警告都列在那里）。

## 它干了什么

| 块 | 作用 |
|---|---|
| `scenes` | 加了一个新场景「观景台」，带一张 30x12 的字符地图 |
| `scenes`（第二条） | 用 `_op:"patch"` + `_append` 给**已有的**中央走廊开了一扇新门 |
| `interactables` | 加了一台望远镜（按 E 打开「观星笔记」）和一扇舷窗（按 E 看一眼外面） |
| `npcs` + `schedules` | 加了一个人「观星者 柯」，24 小时待在观景台 |
| `dialogues` | 加了一段三选项的对话 |
| `views` | 加了一个终端界面 |
| `npcApproach` | 让他每次见到你都会先提一句 |

## 想改什么就改什么

- 想让新场景更大：改 `size` 和 `tiles`。**每行长度必须等于 `size.w`**，不对的话会自动补齐并在 F3 里警告。
- 想让门通向别处：改 `exits[].to`。
- 想让他走动：在 `schedules[0].slots` 里加时段。
- 想加第四个选项：在 `dialogues[0].nodes.root.options` 里加一条 `{"text":"...","goto":"end"}`。
- 想加新效果：所有效果词见 `engine/space-core.js` 顶部注册表，或者直接在 mod 里调用已有词组合。
